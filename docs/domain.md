# 算力词元结算网领域约定

服务采用事件时间与接收时间分离的记录方式。所有业务身份由调用方提供的
稳定标识表示，审计记录不得以覆盖方式修改。

## 计量与归属

- 计量事件以 `(tenantId, eventId)` 幂等去重，可乱序、可重放；重复事件
  返回 `duplicate` 且不产生任何账目。
- 归属维度：租户 + 模型 + UTC 对齐的固定长度计量窗口（默认 60 秒）。
- 结算周期为租户结算时区的自然月（如 `2026-01`）；事件按事件时间归入
  周期，与接收时间无关。

## 计价与抵扣

- 费率按模型版本化，以 `effectiveAt` 生效；事件按其发生时间匹配版本，
  历史用量不受新版本影响。
- 抵扣顺序：套餐周期内词元额度（先输入后输出）→ 预付钱包 → 后付欠费。
- 预付钱包按结算币种记账，扣减与记账原子完成，并发下不可透支；不足
  部分记为后付欠费进入账单。
- 金额一律以百万分之一货币单位（micro）的整数存储与运算；多币种按
  事件时间的生效汇率折算为租户结算币种。

## 账目与更正

- 账目（充值 / 计费 / 冲正）为追加式流水，任何更正通过冲正分录完成，
  历史分录永不改写；冲正中预付部分即时退回钱包。
- 周期关账后出具账单；此后到达的迟到事件路由到其后第一个未关账周期，
  并保留 `lateForPeriod` 关联，在账单行上可见。
- 关账后的争议冲正计入当前未关账周期，随下一期账单结算。

## 证据与可靠性

- 每条被接受的计量事件生成规范 JSON 载荷的 HMAC-SHA256 签名证据；
  账单行逐项携带证据引用与聚合签名，可独立重算核验。
- 窗口用量相对滚动基线异常放大时生成异常记录（`flagged`），处置状态
  为 `confirmed` 或 `waived`；豁免自动冲正该窗口全部计费。
- 所有状态变更先写入追加日志再应用到内存；重启后重放日志恢复状态，
  聚合可无缝继续。
