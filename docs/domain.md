# 算力词元结算网领域约定

本服务独立承接计量摄取到月底关账的完整链路，面向跨时区、多币种的东盟企业租户。

## 基本原则

- **事件时间与接收时间分离**：`occurredAt`（调用方签名，可带时区偏移）在入口归一化为 UTC，
  决定时间窗、费率版本与归属周期；`receivedAt`（服务端）只用于审计与迟到判定。
- **身份由调用方稳定标识提供**：`eventId`、`tenantId` 等均为外部稳定 ID，服务端不臆造业务身份。
- **审计只追加、不覆盖**：更正通过冲正条目（reversal）完成，原始账单、扣款、计量事件永不改写。
- **整数金额**：所有金额以微单位（1 货币单位 = 1e6）的整数表示，支持 USD/SGD/MYR/THB/PHP/IDR/VND/CNY/JPY。
- **结算周期**：UTC 自然月（`YYYY-MM`）。

## 计量摄取

- 事件按 `(tenantId, model, eventId 所属 5 分钟事件时间窗)` 去重，乱序到达与重放均幂等。
- 事件须携带 HMAC-SHA256 签名，载荷为 `eventId|tenantId|model|occurredAt|quantity|unit`。
- 令牌桶突发限流：超出桶容量返回 `429 throttled` 与 `retryAfterMs`，事件未入账，可重试。
- 费率版本按事件时间解析：新版本只影响生效时间之后的用量。
- 同一租户的扣减在互斥临界区内串行：先扣套餐额度包（按优先级、到期时间），剩余按量计价，
  预付余额不足时事件被拒绝（`422 insufficient_funds`）且不占用去重键，绝不透支。

## 关账与迟到事件

- 周期结束后方可关账；关账后不可重开，账单不可修改。
- 关账后到达的事件若归属已关账周期，自动进入**下一个未关账周期**，
  用量记录保留 `originalPeriod` 与 `late` 关联。
- 账单按模型分行，每行含全部用量 ID 与证据摘要 `evidenceDigest`，
  可通过证据接口逐项追溯到原始签名计量事件，并可重新计算摘要校验。

## 争议与异常

- 争议更正生成金额相反的冲正账本条目，关联 dispute，原始条目保留。
- 异常峰值以滚动窗口基线（超过基线倍数且高于绝对下限）自动开立
  `pending_review → approved | rejected` 状态机；`rejected` 时对窗口内已扣费用逐笔冲正。

## 故障恢复

- 所有状态变更先写 `journal.jsonl`（WAL）再应用内存；重启时重放日志继续聚合，重放幂等。
- 可执行快照（`snapshot.json` 原子替换）缩短恢复时间，快照之后的日志增量重放。
